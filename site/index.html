Honest boundaries

A structural audit is not scientific truth.

ReproWeave does

  • Preserve exact evidence locators
  • Keep “unknown” distinct from “no”
  • Validate references and task cycles
  • Hash the complete source snapshot

It does not

  • Judge correctness, novelty, or integrity
  • Run untrusted paper repositories
  • Infer missing evidence with an LLM
  • Claim formal systematic-review compliance

Python 3.11+

Start with the fictional workspace.

python -m pip install reproweave
reproweave demo my-review
reproweave audit --workspace my-review
reproweave report --workspace my-review
